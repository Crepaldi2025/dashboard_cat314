# Documentação — ClimaCast

Esta pasta reúne a documentação técnica, científica e didática da aplicação ClimaCast.

O sistema foi desenvolvido no âmbito da disciplina CAT314, do curso de Ciências Atmosféricas da Universidade Federal de Itajubá (UNIFEI).

A documentação compreende os fundamentos metodológicos, as fontes de dados, as orientações de utilização e os procedimentos de implantação da aplicação.
