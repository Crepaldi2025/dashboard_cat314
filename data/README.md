# Dados auxiliares — ClimaCast

Esta pasta reúne arquivos de dados auxiliares utilizados pela aplicação ClimaCast.

Os dados meteorológicos obtidos de serviços externos, como o Google Earth Engine, não são necessariamente armazenados neste repositório.

A documentação dos conjuntos de dados deve identificar suas fontes, resoluções espacial e temporal, unidades físicas e limitações de utilização.
